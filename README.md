# ScreenShotMap

A QGIS plugin that exports the current map view as a DIN A4 PNG with scale bar, data sources, north arrow and date.

## Features
- Keeps the current map canvas extent exactly as it is
- Fits the map onto a DIN A4 landscape page (297 × 210 mm)
- Adds a right-aligned scale bar and left-aligned data sources
- Generates a north arrow as SVG at runtime
- Exports a ready-to-use PNG file

## Requirements
- QGIS 4.0 or later

## Installation
1. Download or clone this repository.
2. Copy the plugin folder into your QGIS plugin directory.
3. Enable the plugin in the QGIS Plugin Manager.

## Usage
Click the camera icon in the toolbar or open the plugin menu entry. Choose where to save the PNG file.
